This is the source for my static site hosted on Github Pages and generated by [Zola](https://www.getzola.org/). It is automatically built on push using Github Actions.

## Contributing
I am open to suggestions on the content of the website, though any stylistic suggestions should likely be forwarded to the [repository of the theme](https://github.com/ebkalderon/terminus). Small edits like small grammar fixes are suitable for pull requests, but any other comments or questions should be issues. Please specify the page of my website that you are referring to.
